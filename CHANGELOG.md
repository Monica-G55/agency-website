# CHANGELOG

## NorthPeak Digital – Optimization Changelog

### 1. Improved Semantic HTML
- Used semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
- Result: Improved accessibility and SEO.

### 2. Responsive Layout
- Built a responsive layout using CSS Grid, Flexbox, and media queries.
- Tested at 360px, 768px, and 1440px.
- Result: Better user experience across mobile, tablet, and desktop devices.

### 3. Accessibility Improvements
- Added proper labels for form fields.
- Used ARIA attributes for navigation and form validation.
- Improved color contrast and keyboard accessibility.
- Result: Lighthouse Accessibility score improved.

### 4. Performance Optimization
- Used lightweight HTML, CSS, and JavaScript.
- Avoided unnecessary libraries and large assets.
- Optimized code structure for faster loading.
- Result: Lighthouse Performance score improved.

### 5. Contact Form Validation
- Added client-side validation for name, email, budget, and message fields.
- Displayed clear error messages for invalid input.
- Result: Better user experience and fewer invalid submissions.

### 6. Mobile Navigation
- Implemented a responsive navigation menu with JavaScript.
- Result: Smooth navigation on smaller screens.


# AI Usage

I used AI to brainstorm content, improve the wording of sections, and review accessibility and responsiveness. I customized the final layout, styling, interactions, and implementation based on my own decisions, then manually tested the website before deployment.
